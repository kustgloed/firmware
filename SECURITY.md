# Security reports

Send vulnerability reports privately to support@kustgloed.nl. Include the
affected firmware version, the impact, and enough information to reproduce
the issue. Keep credentials and personal data out of the report.

Expect an acknowledgment within seven days. Please keep the report
private until a fix is available and disclosure has been coordinated.
